# Pokémon Chuyển Sinh v1.5.36 — independent skill choices in competitive multiplayer

**Goal:** Sống Còn (Royale) and Tranh Trứng (Egg Rush) continue in real time while any trainer is picking level-up skills. Only Sống Sót (Co-op) pauses the team for shared leveling and waits for all players.

## Approved mechanics / implementation

- Competitive Royale/Egg Rush: **no room-wide pause or `waiting` barrier** for skill-card selection. Host `G.Coop.levelStart` increments a sequence and sends a skill choice to each participant, then returns immediately. The actual game remains `state='playing'` while a particular player has their level card UI open. All other humans and AI can move, attack and collect, and the Host clock, monsters, red zone and egg timers keep updating.
- A selecting trainer's local movement is frozen while their cards are shown; they can still be attacked. Competitive skill selection is not an invulnerability exploit and does not change match outcomes, leaderboard results or personal rewards.
- The skill chooser uses the existing `G.RunUI.showLevelUp(..., false)`, closing after that player selects one card; no "Waiting for teammates" message and no team-wide resume event. Reroll and number-key shortcuts are retained.
- Multiple levels earned in close succession **queue individual choices** rather than overwriting a player's open picker. The Host includes latest level sequence in every subsequent peer frame. Guests reconstruct each missed level sequence once if a packet drops, avoiding missed cards / repeated card rewards.
- Item replacement and Pokémon move-bond selections also stop **only the individual player** in competitive modes; they do not send global `holdStart`/`holdEnd` events.
- **Sống Sót Co-op is deliberately unchanged:** synchronous level cards, Host waiting list, all teammates select then `resume`, shared item/bond pauses and revive rules remain intact.
- Keep the existing multiplayer XP/level accrual logic for this narrowly scoped pause fix; each participant's **selected skill effects** are applied to their own Pokémon. Do not silently refactor XP ownership or nerf level curves in this release.
- Clear pending personal card queues on new matches. No save or permanent meta progression change; preserve all prior v1.5.35 Chapter 0–3 purple Gacha ticket rewards, private ticket/Shiny ownership, v1.5.34 Egg Rush scoring, 10-trainer cap and v1.5.32 Rift fixes.

## Source / acceptance gates

- `scripts/patch-competitive-levelup.cjs` runs after previous game patches in `scripts/prepare-game.cjs` and modifies compiled `js/net/coop.js` and `js/game.js` for PC, Web/HTML5+iOS PWA, Android.
- `tests/competitive-nonblocking.test.cjs` checks mode routing, Co-op waiting preserved, sequence-idempotent guest queue reconstruction, local movement freezing and compiled patch presence. Included in relevant platform test suites.
- `tests/coop-platform-browser.cjs` opens a real Royale/Egg Rush Host+AI match in packaged Web/Android, triggers **two consecutive** level choices and verifies `G.Game.state==='playing'`, timer continues while first card is open, the second card remains queued, and the round still plays after both choices. Existing Co-op mode tests and ten-minute ten-trainer P0 soak remain enabled.
- If Host/client becomes disconnected or the player leaves the match, pre-existing network/away behavior is preserved. A room-wide pause must not be triggered **solely** by an opponent opening a skill, item or move-choice panel.
