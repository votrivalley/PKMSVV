# 1.5.22 — Android Co-op menu and local AI

Android FULL LAN now opens the same Sống Sót / Sống Còn / Tranh Trứng menu as
Web and PC. It no longer jumps directly to native PC discovery from the main
Co-op menu row. The upstream CSP blocked inline platform/AI flags; these now
load from external scripts allowed by the existing policy. Direct menu callbacks and shared capture handlers use the same
dialog, including offline builds without MultiplayerUI.

The APK contains the real standalone AI gameplay engine previously added on
Cloudflare. AI launches locally with no PC, socket or Firebase. Existing valid
partner saves are retained. Full game assets are reused, not duplicated for AI.
Web and Android use the same AI packaging helper and copied support scripts.
Bots are selected from the game dex and cleared after a completed AI round.

Human multiplayer still uses PC LAN Host. Android passes role and mode to its
native picker; Web accepts the Host invitation. A standalone Android or static
Web server for other human clients has not been implemented in this release.

Validation: see `tests/coop-platform-browser.cjs` for entry-menu, native dispatch,
real AI gameplay, controlled match checkpoints, end-of-match and second-round
coverage. The Android browser check serves the APK's web assets with a mock
native bridge; native Wi-Fi and installed-app behavior require device QA.
