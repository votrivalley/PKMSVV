# Pokémon Chuyển Sinh v1.5.37 — Royale elimination spectator and accurate rewards

Date 2026-10-28. Branch `feature/lan-local-beta`; `main` unchanged.

## Report and fixed behavior

- User screenshot: in **Sống Còn** (Survival Royale), a trainer already at HP 0 continues to see a level-up screen, blocking their observation of the match. Elimination is permanent in Royale, so **cancel any open skill/item/bond screen immediately** and never grant another level-card to a fallen trainer. Handle both current independent picker and legacy `state='levelup'/'choice'` left by older network messages; reset those states to `playing` before processing input so Host world continues.
- After elimination, the defeated trainer enters **spectator mode** in the SAME running match, automatically focusing an alive human or bot. They can switch targets via two small **‹ / › buttons** or **left/right arrow keys** on PC. Show the target trainer name and living spectator index. Camera smoothly follows target coordinates using the existing `G.Camera.follow`, avoiding new network/camera events. If target is eliminated or disconnects, automatically select another living trainer; if none survive, hide selector while the Host finishes.
- Keep spectators eliminated: **no revival, invulnerability, teleporting the dead body, PvP, additional skills, item purchases, live match control, or save changes**. HUD death copy and ranking continue functioning. UI is a compact responsive fixed bottom strip for Web, PC and Android; mobile buttons are touch-friendly. Show ONLY in Royale while eliminated and match not over. Do not show in Sống Sót (Co-op) because teammates can revive, or in Tranh Trứng because the 8-second respawn is intentional.
- Preserve previous Co-op team-wide synchronous card picks; independent competitive choices, AI legal skill upgrades and v1.5.35 chapter-purple rewards unchanged.

## Current actual money/points (informational only; NO economy change in this release)

- Both **Sống Sót and Sống Còn** currently use the *same basic end-run PokéCoins formula*, inherited from `js/game.js`:
  `round((floor(seconds/5)+floor(kills*0.25)+80*bosses+coinsPickedUp)*coinMul)`.
- Royale **standings points**, from `src/web/pkmsvv-royale.js`, are `floor(secondsAlive)*10 + (winner?1000:0)`. **Those points are not PokéCoins and are not exchanged for PokéCoins.** There is no extra PokéCoins payout by placement #1..#10 in the code as of v1.5.37.
- Competitive ticket pickups and wild Shiny are **private to the collector/last-hit trainer** per `scripts/patch-competitive-rewards.cjs`; Co-op retains shared tickets and Shiny. Do not conflate ticket pickups with an end-of-match bonus or change the economy unrequested.
