## Deployment boundary

Cloudflare Pages production domain `pkmsvv-web.pages.dev` does not change when uploading new HTML5 files. GitHub's `build-cloudflare-html5.yml` deploy step is intentionally gated behind `workflow_dispatch` with `publish=true` and existing authorized Cloudflare secrets; ordinary CI push only creates ZIP artifacts. Never announce that live site is updated solely because CI passed. Back up JSON before a migration or deleting local browser storage; do **not** clear user cache/save as a shortcut.
