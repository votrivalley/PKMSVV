# PKMSVV v1.5.31 — Issue #8 gameplay + ranked Pokémon results

Date: 28 October 2026. Branch: `feature/lan-local-beta`. **Not merged to main**.

## User-approved gameplay changes

- **Egg Rush / Tranh Trứng:** Host accepts an egg only through the existing validated claim path. A match finishes **exactly once** on the first condition reached: a trainer collects **6 scoring eggs** (early winner), the lobby collectively collects **10 scoring eggs**, or the **12-minute** safety deadline. Duplicate, expired or post-result take events do not add score. 4-player ranking is always generated, including AI.
- **Survival Royale / Sống Còn:** the full 2–10-player roster must be instantiated; when exactly one trainer remains, Host ends **immediately, even before 6 seconds**. If no trainer survives, present a deterministic draw. The result preserves every member #1..#N, elimination duration/points, including AI and all deaths at the same clock tick.
- **End-of-match leaderboard on BOTH competitive modes:** full scrollable ranking appears in the usual finished-match screen; **each individual row has rank, the correct SpriteCollab Pokémon canvas from the actual player's DEX, the real trainer/AI name, and eggs or survival points/time**. Shiny portraits remain Shiny if the roster member was Shiny. Champion and the user's own row highlighted. On small landscape devices rankings scroll within the modal and cannot truncate lower positions. This is **not** the compact one-row live Survival HUD.
- **Host-owned AI balance:** at room creation/update every real human shares an allowlisted, capped *effective purchased combat-perk preview only* (HP, ATK, SPD, cooldown, reduction, regeneration), not any save file. Host takes the strongest real human snapshot at match begin (including other Wi-Fi guests, not only Host; never compares against other bots). In Tranh Trứng **every AI** is at least this strong; Sống Còn and Sống Sót guarantee **one challenger AI** at least this strong. Existing randomly varied other Royale AI tiers remain. For friendly Co-op strong AI, hostile spawn density is raised modestly (bounded). No per-frame scaling, no duplicate bonuses on re-entry, no trainer save mutation, no modified ability/nature/TM. Human upgrades remain their own.
- **Web AI deep link:** public direct entry is https://pkmsvv-web.pages.dev/ai/game/ ; the existing v1.5.30 hotfix prohibits any automatic five-second version reload in standalone AI/LAN. Do not clear origin cache/save to fix a missing update. Production Cloudflare is **not** changed by GitHub CI until separately deployed.
- Preserve v1.5.30 independently scrolling menu columns, on-field red **vòng đỏ** label, compact Survival HUD, three mode-specific death messages, support/Orb mechanics, personal Shiny/tickets and 10-person maximum.
