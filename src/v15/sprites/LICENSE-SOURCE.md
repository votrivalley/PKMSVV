# Egg/Nest sprite provenance and license

The following SVG gameplay sprites used in Pokémon Sinh Tồn v1.5 are derived from **original MIT-licensed source code**, not from the Pokémon Survivor Burst Android game payload:

- `egg_follow.svg`: pixel matrix `EGG` in `src/render/art.ts`.
- `egg_crack.svg`: same pixel matrix with a cracked-shell variation inspired by `EGG_CRACK` in `src/render/art.ts`.
- `egg_nest.svg`: egg plus twig-nest composition based on the `nest` renderer in `src/render/fieldMissions.ts`.
- Original project: [Pokémon Survivors by Pedro Barretto](https://github.com/pedrobarretto/pokemon-survivors).
- Source locations: https://github.com/pedrobarretto/pokemon-survivors/blob/main/src/render/art.ts and https://github.com/pedrobarretto/pokemon-survivors/blob/main/src/render/fieldMissions.ts.
- Original copyright: Copyright (c) 2026 Pedro Barretto.
- License for original source code: MIT (text reproduced below).

We have rebuilt the pixel graphics as local, self-contained SVG sprite files and adjusted their dimensions for PKMSVV. **The Pokémon character sprite sheets under the other project's `public/assets/` are not copied.** Character graphics have separate licenses.

These SVGs are intentionally independent of `src/story-art/` Chapter 3 cutscene illustrations.
